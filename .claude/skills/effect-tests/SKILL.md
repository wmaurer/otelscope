Choose the behaviours to cover from the task's acceptance criteria before you edit. Put each test in the existing test file for the module, and read the tests near it for imports and structure.

Import `describe`, `it`, and `assert` from `@effect/vitest`:

- Use `it.effect` for a test that returns an Effect. Use plain `it` for a pure synchronous test.
- `it.effect` provides a `Scope` and closes it when the test ends. Return a scoped effect directly. Do not wrap the body in `Effect.scoped`.
- Use `assert`, not Vitest's `expect`.
- `it.effect` runs on `TestClock`, so time moves only when the test moves it. Import `TestClock` from `effect/testing` and call `TestClock.adjust` to complete sleeps and schedules. Use `it.live` only when a test needs the real clock.
- `it.effect` runs the effect. Keep `Effect.runSync` and `Effect.runPromise` out of tests.

For parameterized tests (`it.effect.each`), property tests (`it.effect.prop`), and services shared through `layer`, read the examples in `packages/<pkg>/node_modules/effect/ai-docs/src/09_testing/`.
