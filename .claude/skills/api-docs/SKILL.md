This skill is generated by project-setup from `agent-skills.config.js`. Do not edit it here: `pnpm skills:check` fails on any change, and `pnpm skills:sync` writes it again.

The doc comment of an export is what a consumer reads on hover and in generated reference docs. It says what the API does now and when to use it, in practical English about the public concept, not its implementation.

## Workflow

1. Read the declaration, its implementation, the nearby JSDoc, its tests, and its call sites.
2. Choose each branch that applies, and read its reference before you edit:
    - the comment shape, tags, module comments, or links: [declarations.md](declarations.md);
    - categories: [categories.md](categories.md);
    - examples: [examples.md](examples.md).
3. Make a focused fix to one API, or refine one module. Keep verified facts and useful examples. Rewrite only what is wrong or missing.
4. When you refine a module, or the API has close alternatives, check each `@see` link. Read the implementation and tests for concrete **Gotchas**.
5. Run `pnpm lint` and `pnpm typecheck`.

## Rules for every comment

- Write a multiline `/** ... */` block with one self-contained description paragraph.
- Start a function or method with a present-tense verb, such as `Creates`, `Returns`, or `Converts`. Start a value with the noun phrase that the nearby values use, such as `Schema for` or `Layer that`.
- The optional sections `**When to use**`, `**Details**`, and `**Gotchas**` appear at most once each, in that order. Leave out a section that has nothing to say.
- `**When to use**` states a use case that the description does not already say. Reserve `**Gotchas**` for concrete preconditions, edge cases, surprising behavior, and failure modes.

A declaration marked `@internal` is not public API. Public docs do not cover it.

The task is complete when each changed public declaration meets every reference that applies to it, each example compiles against the public imports, and `pnpm lint` and `pnpm typecheck` pass or are reported as not run.
